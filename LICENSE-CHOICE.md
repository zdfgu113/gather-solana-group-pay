# License choice pending

No `LICENSE` file has been added. This package intentionally leaves the legal choice to the project owner and does not make a licensing commitment on their behalf.

Common options to consider before creating the GitHub repository:

| Choice | Practical effect | When it fits |
| --- | --- | --- |
| MIT | Short, permissive, widely recognized in hackathons | Recommended if public reuse with attribution is acceptable |
| Apache-2.0 | Permissive with an explicit patent-license framework | Consider if the additional patent terms are desired |
| No license, private repository | Review access can be limited to invited people | Fits a review-only submission while the owner decides |

This is a project-management summary, not legal advice. Add a license only after the owner explicitly selects one and confirms they can license every included contribution and asset. The photograph in `public/pottery-cover.jpg` has separate attribution in `docs/photo-credit.md`.
